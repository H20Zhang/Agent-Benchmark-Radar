# 2026-W36｜Freshness backfill：不是凑 9 月数量，而是补三个漏掉的评测坐标

本周重新扫描 Agent Memory、Agentic Retrieval 与 Data Agents 的近期 primary sources。9 月 1–5 日检索到的方法论文与跨域 agent benchmark 中，没有在证据核验后强行扩张三条 canonical area；更实质的 content debt 是 7–8 月三项可复用 benchmark 漏收。

- **AuthMem-Bench（2026-08-03）**：把 memory consolidation 中的 source authority preservation 变成配对可测对象。
- **Agent Retrieval Bench（2026-07-27）**：把 coding-agent context acquisition 与 patch generation 拆开，并加入 no-gold / counterfactual selective retrieval。
- **PM-Bench（2026-07-14）**：把 prospective memory——未来 cue 到来时记得执行延迟意图——从 retrospective recall 中独立出来。

## So what

Memory 前沿继续从“存了什么”转向“什么时候、以什么权限、为了什么未来行动使用”；Retrieval 则继续从 query-document similarity 转向 workflow-conditioned context utility。相比再增加一批相似 QA，这两类变化更可能改变实验设计。
