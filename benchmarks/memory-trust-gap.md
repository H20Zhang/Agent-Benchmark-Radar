# The Memory Trust Gap：更强的模型也可能更相信过期记忆

**中文** | [English](memory-trust-gap.en.md) · [返回入口](../README.md) · [Benchmark Library](../library/README.md)

[论文](https://arxiv.org/abs/2609.01852) · **领域：Agent Memory**

## 它到底测什么
该基准测量持久记忆与当前权威证据冲突时，模型何时会**错误相信过期记忆**。Benefit 套件中，任务没有记忆就无法完成；Safety 套件中，权威工具始终给出当前正确值，因此两套任务把“记忆有帮助”和“记忆会伤害”明确分开。

## 相比前身多测了什么
StateMemBench、MemTrapBench 等已暴露过期状态和记忆诱导错误；这里新增的关键坐标是**模型能力规模与记忆过度信任之间的交互**，并用受控因子实验分别改变标签、时间新近性、来源权威和位置。

## 评测协议与决定性证据
论文在 Qwen3 0.6B、1.7B、4B、8B 的同系列模型上发现：Benefit 套件里各规模模型都高度依赖记忆；Safety 套件里，更大模型在某些“过期记忆看起来更新”的条件下反而出现更明显的伤害。作者还在 Llama-Instruct 系列和两个外部数据集上验证了主要模式。

## 结论边界
结果支持“持久记忆的信任策略具有模型能力依赖性”，但不能直接推出更强模型普遍更不安全；任务是冻结、封闭集合且受控的，具体失败还依赖记忆呈现方式与冲突构造。

## 剩余缺口与下一步
需要在开放世界、多工具、多来源以及长期写入历史中验证，并区分模型对记忆、普通文档和工具证据的信任策略是否一致。最有价值的最小实验是三臂而不是“有/无记忆”：无记忆、过期记忆、过期记忆+当前权威工具证据，并按同系列模型规模比较。
