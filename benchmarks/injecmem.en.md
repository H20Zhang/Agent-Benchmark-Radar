# InjecMEM

- **Measurement object:** Whether one ordinary interaction can plant memory that is later retrieved by related queries and steers generation to a chosen target.
- **Closest predecessor:** AgentPoison and MINJA emphasize attack methods; MPBench supplies the broader persistent-poisoning taxonomy. InjecMEM isolates topic-conditioned targeted generation.
- **Decisive evidence:** Multi-GCG reaches 46.5% RSR, 76.6% conditional ASR, and 35.6% joint ASR on MemoryOS; common filters barely reduce conditional ASR.
- **Score ceiling:** This supports a white-box optimized attack against the tested stacks, not black-box transfer to unseen model families.
- **Strongest confounder:** The strongest attack requires backbone access and knowledge of the fused prompt.
- **Remaining gap:** Rewrite-heavy stores, deployed systems, adaptive defenses, and calibrated security–utility curves.
- **Genealogy:** It advances memory security from successful writing to a write→drift→retrieve→generate trajectory; `map_delta=reinforces`.

Primary: https://arxiv.org/abs/2608.23471
