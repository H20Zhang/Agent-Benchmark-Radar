# Mr.LHDR

## 测量对象

测长程多模态研究的最终答案，以及受前置依赖约束的中间结论覆盖。

## 相比前身改变了什么

相较只判最终答案的深度研究评测，将满足前置依赖的部分进展变成直接评分对象。

## 协议与比较条件

OA 判最终答案，SA 还要求全部清单项通过；CS 测覆盖，DACS 仅在前置项也通过时计分。发布实现把运行、判分和汇总分开。

## 决定性证据与结论上限

论文报告最高 OA 为 43.1%、SA 为 34.3%。它展示该判分器下答案与过程覆盖的差距，并不意味着直接观测到了系统内部推理。

## 最强混淆与限制

README 的主结果注明 Qwen3-VL-235B 判分，但快速开始示例使用另一判分器。复现数字前必须固定判分器与工具权限；异构系统和实时证据不支持简单的组件归因。

## 未覆盖与下一步实验

标注清单测的是呈现出的证据与结论，不是隐藏推理；其他有效解题路径可能少得分。

冻结证据快照与同一智能体，对比短答案和显式证据输出，并允许独立验证的替代依赖图；解释相邻排名前先检查不确定性。
