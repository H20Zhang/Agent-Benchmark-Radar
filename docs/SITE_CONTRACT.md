# Website retired

The website ceased serving the application on 2026-09-06. Its old URLs contain only
an unindexed handoff to the GitHub README or the corresponding benchmark note.
The source under `web/` is retained, but automatic app publication is disabled.

The active contract is [README-first publication](README_PUBLICATION.md).
Content maintenance does not install, build or deploy the website. Restoring it
requires a new user decision; editing a README or running citation refresh must
never restore Pages publication. Previous visual audits are historical records,
not evidence that the retired application is a supported public interface.
