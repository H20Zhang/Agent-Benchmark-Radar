# 2026-W34 Benchmark Weekly Digest

**Period:** 2026-08-17—2026-08-23 (ISO week 34)  
**Exact synthesis time:** 2026-08-24T00:44:47Z (UTC)  
**Supporting Radar acceptances:** 10  
**Confidence:** medium

The ten auditable acceptances do not form one omnibus trend. The more defensible reading is that RAG produced two independently supported validity claims, Memory continued to split into distinct causal questions, and Data Agents contributed one early evaluator-reliability signal.

## RAG: retrieval scores must bind what was found to whether it helped

[The Recall Trap](../../benchmarks/recall-trap.en.md) observes higher recall alongside lower repair success under a fixed file-slot protocol, while [The Commercial Tax](../../benchmarks/commercial-tax.en.md) shows that license, query format, index construction, and cost change the deployment meaning of an embedder number. Together they support `retrieval-harness-validity`: a headline retrieval score describes a system under a particular corpus, packing, interface, budget, and downstream protocol; it is not automatically evidence of retriever-component quality.

A second independent set makes coverage more structured. [MAPLE](../../benchmarks/maple.en.md) tests whether one paper remains retrievable across aspects, [VisDocAgentBench](../../benchmarks/visdocagentbench.en.md) compares static and iterative visual retrieval under one top-10 contract, and [WANDR](../../benchmarks/wandr.en.md) combines open-set live-web discovery with record-level verification. This reinforces `structured-evidence-coverage`, but their environments differ and they are not leaderboard replications of one another.

## Agent Memory: this is coordinate splitting, not one-way maturity

[PAST-Bench](../../benchmarks/past-bench.en.md) uses persistence-on/off intervention to ask whether memory causally improves later action; [SP-Mem](../../benchmarks/sp-mem.en.md) places personalization, consent, exact-value exposure, and cost in one lifecycle protocol; [MemFuseBench](../../benchmarks/memfusebench.en.md) diagnoses cross-source linking, causal fusion, conflict, and provenance. Together they show that memory quality no longer fits one recall axis, but each coordinate has only one acceptance signal this week and cannot be called an established trend.

## Data Agents: audit the evaluator before interpreting the leaderboard

[data-eng-bench](../../benchmarks/data-eng-bench.en.md) repaired Snowflake verifier and environment behavior, exposing a reproducibility boundary: hidden tests and the execution environment can create or erase apparent success. No complete post-fix leaderboard rerun is public, so this remains an `early_signal` for `executable-verifier-reliability`, not evidence that model or scaffold rankings changed.

## Research-design implication

The most useful next comparison is not another total-score column but matched controls: RAG should jointly report evidence exposure, evidence use, and downstream success; Memory should use paired persistence or risk-state interventions; Data Agent evaluations should rerun against fixed environment images and verifier versions. Only then can “this system is stronger under this protocol” become attributable component evidence.
