## Make the failure stage observable before choosing a stronger agent

[LoCoMo-Conv](../../benchmarks/locomo-conv.en.md) holds histories and evidence identifiers fixed while varying the current request. [MemCalib](../../benchmarks/memcalib.en.md) instead supplies memory propositions and tests how strongly each should influence the answer. [DolphinBench](../../benchmarks/dolphinbench.en.md) carries historical context into scored actions with frozen memory checkpoints.

These measure different stages: identifying relevant evidence, using it at the right strength, and converting it into an action. A successful action can hide weak memory, while high evidence recall can coexist with an inappropriate response. The three records therefore support a staged experimental design; they are not independent replications of one score improvement.

**Research-design implication:** compare retrieved evidence with supplied-correct-evidence, then hold the answerer and executor fixed. Report retrieval, memory-use calibration, action success and lifecycle cost separately. DolphinBench certification depends on its certification agent; MemCalib's scorer release remained unverified at its recorded review, so do not treat all stages as equally executable.

## Separate problem formulation, evidence discovery and fluent output

[StatFormBench](../../benchmarks/statformbench.en.md) makes the analysis formulation inspectable before code executes. [LiveDRBench](../../benchmarks/livedrbench.en.md) represents broad research as structured claim discovery rather than judging report style. [ChemCLIR-Bench](../../benchmarks/chemclir-bench.en.md) exposes language-pair and ranking-depth failures in technical retrieval.

Together they motivate asking which intermediate object is wrong before attributing a final failure to general reasoning. Their reference labels, source languages, judges and tasks differ; this is a comparison of measurement designs, not a pooled benchmark ranking or a demonstrated universal trend.

**Research-design implication:** supply an expert formulation or a controlled evidence set to the same downstream system. Keep formulation quality, retrieval coverage, claim precision/recall and final artifact quality distinct. Audit translated-query and document-field asymmetry in cross-language retrieval, and allow valid discoveries outside incomplete reference sets.
